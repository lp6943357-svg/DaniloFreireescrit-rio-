# Danilo Freire Advogados

Website profissional em Next.js 14, React 18, TypeScript e Tailwind CSS.

## Desenvolvimento
`npm install`
`npm run dev`

## Produção
`npm run build`
`npm start`

## Deploy
O projeto está preparado para Vercel. O domínio canônico configurado no SEO é `https://danilo-freire-advogados.com`; se outro domínio for usado, atualize `app/layout.tsx`, `app/sitemap.ts` e `app/robots.ts`.
